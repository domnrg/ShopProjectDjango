# Django Интернет-магазин

Учебный проект интернет-магазина на **Django**.  
Реализованы главная страница и страница обратной связи (контакты).  

## Возможности
- Главная страница с товарами (заглушка).
- Страница "Контакты" с формой обратной связи:
  - Поля: имя, телефон, сообщение.
  - Валидация данных.
  - Отображение уведомления об успешной отправке.

## Технологии
- Python 3.10+
- Django 5.x
- Bootstrap 5 (для верстки форм)

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/ShopProjectDjango.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
```

3. Создайте базу данных и выполните миграции:
```
python manage.py migrate
```

4. Запустите локальный сервер:
```
python manage.py runserver
```
## Использование:

Перейти в браузере:

Главная: http://127.0.0.1:8000/
Контакты: http://127.0.0.1:8000/contacts/
